Документация программы "CtoTeX"

О проекте

Данная программа предназначена для перевода выражения на языке C++, записанного в обратной польской записи, в формулу формата TeX для удобного отображения на экране или на бумаге.

Программа считывает выражение из входного файла и параметры отображения из файла конфигурации, разбивает на токены, строит абстрактное синтаксическое дерево (AST), применяет настройки отображения и генерирует TeX-строку, которая сохраняется в выходной файл.

Использование

CtoTeX.exe <expression_file> <config_file> <output_file>
  • <expression_file> : путь к текстовому файлу, содержащему выражение в обратной польской записи
  • <config_file> : путь к текстовому файлу с параметрами отображения
  • <output_file> : путь для сохранения результата (TeX-строки)

Пример

Входной файл (expression.txt):

x x x * *

Входной файл (configuration.txt):

mulIdenVar powVarN

Выходной файл (output.txt):

x^{3}

Основные функции

  • tokenizeExpression: Разбивает строку выражения на токены (числа, переменные, константы, операторы)
  • buildTree: Строит AST на основе токенов, проверяет совместимость типов операндов и обрабатывает ошибки
  • cToTex: Рекурсивно обходит дерево и генерирует TeX-строку с учётом приоритетов операций, ассоциативности и настроек отображения
  • validateConfigFile: Проверяет корректность файла конфигурации и сохраняет параметры отображения
  • printErrors: Выводит сообщения об ошибках в консоль

Ошибки

Программа корректно обрабатывает и выводит информативные сообщения о различных ошибках, таких как:

  • Файл не найден или не удалось создать выходной файл
  • Недопустимые символы в выражении
  • Недостаток или избыток операндов
  • Превышение максимального количества узлов (1000)
  • Имя переменной длиннее 255 символов
  • Число вне диапазона [-2*10^9, 2*10^9] или слишком много знаков после запятой
  • Несовместимые типы операндов (арифметика с логическими операндами)
  • Оператор не окружён пробелами
  • Ошибки в файле конфигурации (несуществующий параметр, недопустимое значение, дублирование)
